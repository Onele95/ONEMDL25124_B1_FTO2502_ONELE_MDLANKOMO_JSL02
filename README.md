# 🚀 Kanban Board - Project Management Tool

## 📝 Description  
A responsive Kanban board application built with **pure HTML and CSS** that helps users visualize and organize tasks into customizable columns (To Do, Doing, Done). Features a toggleable sidebar, mobile-responsive design, and intuitive visual interface.

## 🛠 Technologies Used  
- **Frontend**: HTML5, CSS3  
- **Font**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) 
- **Design System**: CSS Variables for theming  
- **Responsive Layout**: Flexbox + Media Queries  

## ✨ Key Features  

### 🖥 Interactive UI
- Visual hover/focus states for all interactive elements  
- Task cards with elevation effect on hover  
- Color-coded column indicators (blue, purple, green)  

### 📱 Responsive Design
- Mobile-first responsive layout  
- Sidebar toggles on mobile (≤768px)  
- Columns stack vertically on small screens  

### ⚡ Pure CSS Implementation
- No JavaScript dependencies  
- Checkbox hack for mobile menu toggle  
- CSS-only visual feedback    

## 📱 Mobile Interaction

### 🎯 Basic Controls
- **☰ Menu Toggle**  
  Tap the icon in the top-left corner to show/hide the sidebar (please note: the sidebar only shows on tap but does not hide at the moment, this will be rectified when we doing javascript)

- **Column Navigation**  
  ↕️ Scroll vertically through stacked task columns
